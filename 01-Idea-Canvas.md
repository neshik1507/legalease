# LegalEase Idea Canvas

| Area | Decision |
|---|---|
| Problem | Manual/repetitive first-draft preparation |
| Product | AI-assisted legal document drafting |
| AI | Google Gemini |
| Frontend | Streamlit |
| Backend | FastAPI |
| Input | Document details, parties, dates, terms |
| Output | Draft + TXT/DOCX/PDF |
| Primary value | Faster structured first drafts |
| Human role | Review and validate generated content |
| Main risk | Incorrect or unsuitable AI-generated text |

## Success Criteria

- Application launches successfully.
- User can submit a document request.
- Backend validates the request.
- Gemini generates a structured draft.
- Draft is displayed in the frontend.
- Export buttons generate valid files.
- Errors are presented clearly.
