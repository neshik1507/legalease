# LegalEase User Manual

## 1. Launch

Start the backend:

```bash
uvicorn backend.main:app --reload
```

Start the frontend:

```bash
streamlit run frontend/app.py
```

## 2. Enter Information

Fill in:
- Document type
- Party A
- Party B
- Effective date
- Terms and conditions
- Optional additional instructions

## 3. Generate

Click the generation button and wait for the AI response.

## 4. Review

Read the complete generated draft. Check:
- Names
- Dates
- Amounts
- Responsibilities
- Terms
- Missing information

## 5. Export

Choose the required format:
- TXT
- DOCX
- PDF

## 6. Important Notice

Do not treat generated text as guaranteed legal advice or as automatically valid for a particular jurisdiction. Review the document appropriately before real-world use.
